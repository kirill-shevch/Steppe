# Steppe World Model v2

Автономная конечная симуляция степи и её 2D-наблюдатель. Модель не зависит от Unity, положения игрока, `GameObject`, кадровой частоты или рендеринга.

Это первый вертикальный срез новой архитектуры:

```text
Солнце → тепло → давление → ветер
                     ↓
граница мира → влажность → облако → дождь / снег
                                 ↓
      испарение ← почва ← поверхность → сток
                     ↓
               растительность → сухая масса → почва
```

Вместо первичного `BiomeId` каждая ячейка хранит физическое состояние. Название вроде «луговая степь» вычисляется только при наблюдении.

## Быстрый запуск Observer

Из корня Unity-проекта:

```powershell
dotnet run --project WorldModel/Steppe.Observer
```

Открыть адрес, который напечатает сервер (обычно `http://localhost:5000`). Размер и seed можно изменить при запуске:

```powershell
dotnet run --project WorldModel/Steppe.Observer -- --size 128 --seed 314159
```

Observer позволяет:

- искать и переключать все 41 наблюдаемое состояние модели;
- читать название, единицу, физический смысл, фиксированную шкалу и распределение каждого состояния из единого каталога;
- видеть поле ветра и направление поверхностного стока как векторы;
- делать шаг на час, день, месяц или год;
- запускать непрерывное время с ускорением `×1 … ×1000`;
- выбрать ячейку и прочитать полный срез её состояний по группам;
- увидеть дельту выбранного состояния за последний вызов `AdvanceHours` и фактический вклад именованных входящих и исходящих потоков;
- явно увидеть остаток изменения, который ещё не разложен по инструментированным процессам;
- читать историю средних состояний мира с шагом 6 часов, сутки или 30 дней;
- закрепить до 16 ячеек и записывать историю любого из их 41 состояния в тех же временных масштабах;
- видеть подтверждённые эпизоды снеготаяния, паводка, озеленения, засухи и пыли с началом, пиком, завершением и числовыми основаниями;
- зафиксировать карту выбранного слоя и после шага времени переключиться на симметричную карту изменений относительно снимка;
- видеть значения, вышедшие за пределы фиксированной шкалы, без скрытого изменения цветов карты;
- следить за входом, выходом и остаточной ошибкой водного баланса;
- скачать бинарное сохранение мира.

## Headless CLI

Пример из исходной спеки:

```powershell
dotnet run --project WorldModel/Steppe.Cli -- --seed 123 --size 256 --years 10 --save world.steppe
```

Продолжить сохранённый мир:

```powershell
dotnet run --project WorldModel/Steppe.Cli -- --load world.steppe --years 1 --save world-after-year.steppe
```

Экспортировать слой для внешнего анализа:

```powershell
dotnet run --project WorldModel/Steppe.Cli -- --seed 123 --days 30 --csv water.csv --layer SurfaceWater
```

Полный список аргументов:

```powershell
dotnet run --project WorldModel/Steppe.Cli -- --help
```

Межгодовая вариативность включена по умолчанию. Параметр `--climate-variability` задаёт её силу от `0` (строго повторяющийся сезонный baseline) до `2`; рабочий квалифицированный пресет использует `1`. Текущий климатический режим доступен через CLI-summary и Observer API `/api/climate`, режим произвольного года — через `/api/climate/year/{year}`.

Климат детерминирован `seed + year`, но годы не являются копиями друг друга. Модель создаёт многолетние влажные и сухие серии, сезонные температурные и влажностные смещения, волны жары и холода, ливневые импульсы и ветровые штормы. Аномалии меняют только атмосферные граничные условия; вода и биомасса не добавляются напрямую в экологические резервуары.

Столетняя проверка разнообразия и восстановления:

```powershell
dotnet run --project WorldModel/Steppe.Stress -c Release -- --years 100 --size 32 --seed 123 --harvesters 0 --climate-variability 1 --sample-days 15 --output WorldModel/StressResults/climate-100y-32-qualified
```

Итоги и границы этой квалификации описаны в [CLIMATE_QUALIFICATION_REPORT.md](CLIMATE_QUALIFICATION_REPORT.md).

## Сборка и тесты

```powershell
dotnet build WorldModel/Steppe.WorldModel.slnx
dotnet run --project WorldModel/Steppe.Simulation.Tests
```

Тесты не требуют сторонних пакетов. Они проверяют детерминизм, разнообразие климатических режимов, устойчивость экологии под аномалиями на нескольких seed, пространственный runoff, астрономическую сезонность, водный баланс открытого мира, сохранение, годовую устойчивость полей, полноту каталогов, сходимость записанных материальных потоков с изменениями резервуаров, ограниченную многоуровневую историю и подтверждение режимных эпизодов с гистерезисом.

## Проекты

| Проект | Ответственность |
|---|---|
| `Steppe.Simulation` | конечный мир, состояния, процессы, persistence и read-only snapshots |
| `Steppe.Observer` | локальный web viewer и API управления временем |
| `Steppe.Cli` | headless-прогоны, сохранение и CSV-экспорт |
| `Steppe.Stress` | многолетняя квалификация состояний, потоков и трендов |
| `Steppe.Simulation.Tests` | исполняемый набор проверок без test-framework-зависимостей |

Подробный контракт состояний и процессов: [WORLD_MODEL.md](WORLD_MODEL.md).

Результаты многолетней калибровки и принятые границы устойчивости: [CALIBRATION_REPORT.md](CALIBRATION_REPORT.md).

## Производительность

Observer по умолчанию использует `96 × 96` ячеек и базовый шаг 3 часа, чтобы длинные прогоны оставались интерактивными. CLI поддерживает сетку до `512 × 512`; для целевой карты спеки используйте `--size 256`. Пространственное разрешение не зашито в алгоритмы.

Это пока причинная coarse-grid модель, а не CFD. Масштаб отображаемого ветра и атмосферной адвекции намеренно согласованы с шагом сетки, а не претендуют на разрешение реальной турбулентности в ячейке 250 метров.
